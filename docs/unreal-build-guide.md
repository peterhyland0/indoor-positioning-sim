# Unreal build guide — node by node

Companion to the project plan. Phase 1 (tower) is **generated by `Scripts/bootstrap.py`**; this guide
covers what must be authored by hand in the editor. Keep the Content Browser folder layout from
`unreal/README.md`. Units: Unreal uses centimetres; the sim's metres × 100.

Conventions used below: `Var: Type = default` for variables; `→` for wiring; "fn" = Blueprint function.

---

## Phase 0b — after first open

1. Double-click `unreal/VerticalGeofenceSim/VerticalGeofenceSim.uproject`. First open compiles
   shaders for a few minutes.
2. If `bootstrap.py` has not run headlessly yet: Output Log → set the command dropdown to **Python**
   → `exec(open('/ABS/PATH/unreal/VerticalGeofenceSim/Scripts/bootstrap.py').read())`.
   You should see the tower in `L_Tower` with `F1…F15` labels, green beacon spheres, a blue
   reference cube in the lobby and `Cam_Cutaway`.
3. Install one Blueprint WebSocket plugin from **Fab** (search "websocket blueprint", free). Enable it
   in Edit → Plugins, restart. Note its node names — they replace the pseudo-nodes `WS_Connect`,
   `WS_Send`, `OnWS_Message` below. If nothing works on Mac, use `HTTP Blueprint`'s
   `Http Request` POST with the same JSON body and skip inbound estimates for v1.
4. Edit → Project Settings → Maps & Modes: Editor Startup Map + Game Default Map = `L_Tower`
   (or uncomment the lines in `Config/DefaultEngine.ini`).

## Phase 2b — `BP_SimConfig` (`/Game/Sim/Bridge`, parent: **Object**)

Holds every tunable + the single seeded random stream. Created once by the Game Instance.

Variables (all *Instance Editable*): one per row of `DT_SimConfigDefaults` with the same name and
sensible type (`Float` for numbers, `Boolean` for True/False, `Integer` for `NumFloors`, `Seed`,
`String` for `BridgeUrl`, `Vector4`-ish or 4 floats for `HoistShaft`/`Stairwell`).
Plus `Rng: RandomStream`, `WeatherDriftHpa: Float = 0`, `SimTime: Float = 0`, `Paused: Boolean`.

fn `LoadDefaults` — `Get Data Table Row Names(DT_SimConfigDefaults)` → for each, `Get Data Table Row`
→ `Switch on Name (Key)` → parse `Value` into the matching variable (`String To Float`, etc.).
Finish with `Set Random Stream Seed(Rng, Seed)`.

fn `RandNormal(Sigma) → Float` — Box–Muller with two `Random Float From Stream(Rng)` calls:
`sqrt(-2·ln(u1)) · cos(2π·u2) · Sigma`. Guard `u1` ≥ 1e-9.

fn `RandBool(P) → Boolean` — `Random Float From Stream(Rng) < P`.

fn `StepWeather(Dt)` — if `WeatherDrift`: `WeatherDriftHpa += RandNormal(WeatherStepHpa · sqrt(Dt))`,
clamp ±3.

fn `MaterialLoss(Tag: Name) → Float` — `Get Data Table Row(DT_Materials, Tag)` → `LossDb`; 0 if missing.

## Phase 2c — `BP_SimGameInstance` (`/Game/Sim/Bridge`, parent: **GameInstance**)

Variables: `Config: BP_SimConfig (object ref)`, `Bridge: BP_SimBridge (object ref)`.

Event `Init` → `Construct Object (BP_SimConfig)` → `Config` → `Config.LoadDefaults` →
`Construct Object (BP_SimBridge)` → `Bridge` → `Bridge.Start(Config)`.

Set it in Project Settings → Maps & Modes → Game Instance Class. Also create `BP_SimGameMode`
(parent GameModeBase, Default Pawn = `SpectatorPawn`) and set it as Default GameMode.

Helper: a **Blueprint Function Library** `BFL_Sim` with pure fn `GetConfig → BP_SimConfig`
(`Get Game Instance` → cast → `Config`) and `GetBridge` likewise. Every other Blueprint uses these.

## Phase 2d — `BP_Beacon` (`/Game/Sim/Beacons`, parent: **Actor**)

Components: `Sphere (StaticMesh, /Engine/BasicShapes/Sphere, scale 0.25)`, collision profile
`RadioTransparent`. Material `M_BeaconAlive`.

Variables: `BeaconId: Name`, `Floor: Integer`, `TxPowerDbm: Float = -59`, `AdvIntervalMs: Integer = 300`,
`Battery: Float = 1.0`, `Alive: Boolean = true`, `State: E_BeaconState`.

fn `InitFromRow(Row: S_BeaconRow)` — copy fields, then `RefreshVisual`.
fn `RefreshVisual` — `State` = Dead if `!Alive || Battery <= 0`, LowBattery if `Battery < 0.2`,
else Alive → `Set Material` to `M_BeaconDead` / `M_BeaconLow` / `M_BeaconAlive`.
fn `Kill`, `Revive`, `SetBattery(F)`, `Nudge(Metres)` (`AddActorWorldOffset`, random XY from `Rng`)
— each calls `RefreshVisual` and `GetBridge().SendEvent(...)` (Phase 5).

## Phase 2e — `BP_Building` (`/Game/Sim/Building`, parent: **Actor**) — one in `L_Tower`

Variables: `Beacons: Array<BP_Beacon>`, `BeaconsById: Map<Name, BP_Beacon>`, `FloorHeight: Float`.

Event `BeginPlay` → `FloorHeight = GetConfig().FloorHeight` → `SpawnBeacons`.

fn `SpawnBeacons` — `Get Data Table Row Names(DT_BeaconLayout)` → for each row:
`z = (Floor+1)·FloorHeight − SlabThickness − 0.3` → `Spawn Actor From Class(BP_Beacon)` at
`(X, Y, z)·100` → `InitFromRow` → add to `Beacons` and `BeaconsById`.
Then `Get All Actors With Tag(BeaconMarker)` → `Destroy Actor` each (editor markers are replaced).

pure fn `FloorFromZ(ZCm: Float) → Integer` — `Round(ZCm / 100 / FloorHeight)`.
pure fn `FloorZCm(Floor) → Float` — `Floor · FloorHeight · 100`.
pure fn `WaypointWorld(Name, Floor) → Vector` — `DT_Waypoints` row `(X, Y)·100`, z = `FloorZCm(Floor) + 90`
(capsule half-height).

`BP_ReferenceStation` (Actor, small cube, tag `ReferenceStation`) — one in the lobby (bootstrap placed a
marker; replace it with this BP). pure fn `ReadPressure → Float`: `Config.SitePressure + Config.WeatherDriftHpa + Config.RandNormal(BaroSigmaHpa)`.

## Phase 2h — `BP_Worker` (`/Game/Sim/Workers`, parent: **Character**)

Components: default Capsule + Mesh (leave mesh empty or a scaled cylinder, material `M_Worker`),
`Label: WidgetComponent` (Screen space, `WBP_WorkerLabel`, draw size 120×70, z offset 120),
`Sensors: BPC_PhoneSensors` (Phase 4). Capsule collision profile `RadioTransparent`;
CharacterMovement: Max Walk Speed = `WalkSpeed·100`, Gravity ok (slabs are collision).

Variables: `WorkerId: Name`, `Platform: E_Platform`, `PhoneState: E_PhoneState`, `AppState: E_AppState`,
`TargetFloor: Integer`, `RouteName: Name`, `Segments: Array<S_RouteRow>`, `SegIndex: Integer`,
`TruthFloor: Integer`, `OnHoist: Boolean`, `EstFloor: Integer = -1`, `HasEst: Boolean`,
`Building: BP_Building`, `Hoist: BP_Hoist`, `MoveTarget: Vector`, `SegTimer: Float`.

fn `InitFromShift(Row: S_ShiftRow)` — copy fields; `Segments` = all `DT_Routes` rows with
`RouteName == RouteName` sorted by `Order` (rows are already in order in the CSV; keep it simple).
Label `SetData`. Then `Delay(StartOffsetSec)` → `NextSegment`.

fn `NextSegment` — `SegIndex++`; if past end → `SegIndex = 0` (loop the shift). `Switch on
E_RouteSegment (Segments[SegIndex].SegmentType)`:
- `WalkTo` → `MoveTarget = Building.WaypointWorld(Param, CurrentFloor())` → `AI Move To`
  (Simple Move To Location works with a NavMesh; **without NavMesh** use a timer that
  `Add Movement Input` toward `MoveTarget` each 0.05 s and finishes when within 30 cm).
  On arrival → `NextSegment`.
- `WaitFor` → `Delay(String To Float(Param))` → `NextSegment`.
- `Wander` → repeat until `Param` seconds elapsed: pick random point within 6 m on the current
  floor (from `Rng`), walk there, wait 2–8 s. Then `NextSegment`.
- `BoardHoist` → floor = `Param == "Target" ? TargetFloor : int(Param)` → `Hoist.Request(self, floor)`.
  The hoist calls back `OnHoistArrived` → `NextSegment`.
- `TakeStairs` → target floor = `CurrentFloor() + int(Param)` → walk the stair path: teleport-free
  version: set `MoveTarget` to the stair door on the current floor, then **lerp Z** over
  `FloorHeight / 0.5 m/s` seconds while walking a 3 m line inside the stairwell hole
  (`Set Actor Location` on a timer; the stair hole in the slab means nothing blocks). Then `NextSegment`.

pure fn `CurrentFloor → Integer` — `Building.FloorFromZ(GetActorLocation().Z)`.

Timer (0.2 s, looping, started in BeginPlay): `TruthFloor = CurrentFloor()`; `Label.SetData(...)`.

fn `ApplyEstimate(EstFloor, Punch: String)` — set `EstFloor`, `HasEst = true`; if `Punch != ""`
show `TxtPunch` for 1.5 s.

**Spawning workers**: in `BP_Building.BeginPlay` after beacons: for each `DT_Shifts` row →
`Spawn Actor(BP_Worker)` at `WaypointWorld("LobbyEntrance", 0)` + random 1 m → set `Building`,
`Hoist` (`Get Actor Of Class(BP_Hoist)`) → `InitFromShift`.

## Phase 3 — `BP_Hoist` (`/Game/Sim/Hoist`, parent: **Actor**) — one in `L_Tower`, inside the shaft

Components: `Car: StaticMesh Cube` scale `(2.8, 2.8, 0.2)`, collision profile `RadioTransparent`
but **block Pawn** (workers stand on it): use `Custom` → Radio Ignore, Pawn Block, Visibility Block.
Place at shaft centre `(15.5, 9.5)` m, z = 0.

Variables: `CurrentFloor: Integer = 0`, `Queue: Array<Integer>`, `Riders: Array<BP_Worker>`,
`State: Enum {Idle, Moving, Dwell}`, `TargetFloor`, `Speed`, `DwellSec`, `Waiting: Map<BP_Worker, Integer>`.

fn `Request(Worker, Floor)` — add `Floor` to `Queue` (unique), `Waiting[Worker] = Floor`.
Walk the worker to the car if the car is on the worker's floor, else also enqueue the worker's
floor first (so the car comes to fetch them).

Timer (0.05 s looping) — state machine:
- `Idle`: if `Queue` not empty → `TargetFloor = Queue[0]`, `State = Moving`. Before moving, any
  worker in `Waiting` on `CurrentFloor` and within 2 m: `AttachToActor(Car, KeepWorld)`,
  `OnHoist = true`, add to `Riders`.
- `Moving`: move Z toward `Building.FloorZCm(TargetFloor)` by `Speed·100·Dt`; when reached →
  `CurrentFloor = TargetFloor`, remove from `Queue`, `State = Dwell`, `DwellTimer = DwellSec`.
- `Dwell`: for each rider whose `Waiting` floor == `CurrentFloor` → `DetachFromActor(KeepWorld)`,
  `OnHoist = false`, remove from `Riders`/`Waiting`, call `Worker.OnHoistArrived`. Board any newly
  waiting workers on this floor. Count down; when 0 → `Idle`.

Emit `event` messages `hoistDepart`/`hoistArrive` via the bridge (nice for the dashboard timeline).

## Phase 4 — `BPC_PhoneSensors` (`/Game/Sim/Workers`, **Actor Component**)

Variables: `Owner: BP_Worker`, `Fade: Map<Name, Float>`, `InRegion: Set<Name>`, `ScanTimer: Timer Handle`.

Event `BeginPlay` → `Owner = Cast(GetOwner)` → `StartScanTimer`.

fn `ScanPeriod → Float` — from `Config`: Android/Fg `ScanAndroidFg`, Android/Bg `ScanAndroidBg`,
iOS/Fg `ScanIosFg`, iOS/Bg `0` (no periodic scans; region events only).

fn `StartScanTimer` — clear existing; if `ScanPeriod > 0` → `Set Timer by Function Name("DoScan",
ScanPeriod, looping)`; for iOS/Bg → `Set Timer ("DoRegionCheck", 1.0, looping)`.
Call again whenever `Platform`/`AppState` changes.

fn `ComputeRssi(Beacon) → (Rssi: Float, Heard: Boolean)`
1. `d = Distance(Beacon, Phone) / 100` (m); if `d > MaxRangeM` → not heard. Clamp `d ≥ 0.5`.
2. `LineTraceMultiByChannel` Start = beacon location, End = phone location (capsule centre),
   Channel = **Radio** (`ECC_GameTraceChannel1`), ignore self + beacon. For each hit actor:
   read its first tag among `Concrete/Drywall/Glass/Open` → `loss += Config.MaterialLoss(tag)`.
   (Two hits on the same slab piece — enter and exit — should count once: dedupe on hit actor.)
3. `fade[B] = clamp(fade[B] + RandNormal(FadeStepDb), ±FadeClampDb)`.
4. `rssi = TxPowerDbm − 10·PathLossExponent·log10(d) − loss − (InPocket ? BodyLossDb : 0) − fade[B] + RandNormal(RssiSigmaDb)`.
5. Not heard if `!Alive || Battery ≤ 0 || RandBool(PacketLoss) || rssi < RxSensitivityDbm`.
6. Return `Round(rssi)`.

fn `ReadPressure → Float` — `z = ActorZ/100`; `SitePressure − z·PressurePerMetre + WeatherDriftHpa
+ RandNormal(BaroSigmaHpa) + GustOffset` (gust: `Building.GustOnFloor == TruthFloor && SimTime < GustUntil`).

fn `DoScan` — `Scans = []`; for each `Building.Beacons` → `ComputeRssi` → if heard add `S_Scan`.
Then `GetBridge().SendScan(Owner, Scans, [], ReadPressure(), Ref.ReadPressure())`.

fn `DoRegionCheck` (iOS bg) — for each beacon compute `Heard` as above; if heard and not in
`InRegion` → add, emit `enter`; if not heard and in `InRegion` → remove, emit `exit`. Send a scan
message with `regionEvents` populated and `scans` empty, only when there is at least one event.

Debug: `Config.DebugTraces && Owner == SelectedWorker` → `Draw Debug Line` per beacon, red if
`loss > 0` else green, duration = scan period.

**Verification** (Phase 4 milestone): put a worker on F12 with `Wander`, print the scan list with
`Print String`. `F12-*` should be strongest; `F11/F13` should appear ~18 dB lower and flicker.

## Phase 5 — `BP_SimBridge` (`/Game/Sim/Bridge`, parent: **Object**)

Variables: `Config`, `Socket` (plugin's object), `Connected: Boolean`, `LogPath: String`,
`MsgCount: Integer`, `Backoff: Float = 1`.

fn `Start(Config)` — `LogPath = Project Saved Dir + "Sessions/" + Seed + "-" + Now(yyyyMMdd-HHmmss) + ".jsonl"`;
`Connect`; `SendSession`.

fn `Connect` — `WS_Connect(Config.BridgeUrl)`; bind `OnConnected` (`Connected = true`, `Backoff = 1`),
`OnClosed/OnError` (`Connected = false`; `Set Timer(Connect, Backoff)`; `Backoff = min(Backoff·2, 30)`),
`OnMessage` → `HandleInbound`.

fn `Emit(Json: JsonObject)` — `Json To String` (Json Blueprint Utilities) → `WS_Send` if
`Connected` → **always** append to `LogPath` (`Save String To File`-style node from a file
plugin, or `HTTP Blueprint`-adjacent `File Helper`; if no file node is available, buffer lines in an
array and flush with `Save String Array To File` every 5 s). `MsgCount++`.

fn `SendSession` — build the `session` object per `docs/bridge-protocol.md` from `Config`,
`DT_BeaconLayout`, `DT_Shifts` → `Emit`.

fn `SendScan(Worker, Scans, RegionEvents, Pressure, RefPressure)` — build the `scan` object:
`v, type, t = Config.SimTime, worker, platform, appState ("fg"/"bg"), phoneState ("inHand"/"inPocket"),
scans[{b, rssi}], regionEvents[{b, event}], pressure, refPressure, truth{floor, onHoist, z}` → `Emit`.

fn `SendEvent(Name, Payload: JsonObject)` → `{v, type:"event", t, name, payload}` → `Emit`.

fn `HandleInbound(Text)` — `String To Json` → if `type == "estimate"` → find worker by id
(`Building.WorkersById`) → `ApplyEstimate(estFloor, punch)`.

`SimTime`: a 0.1 s looping timer on the Game Instance: if `!Paused` → `SimTime += 0.1`;
`Config.StepWeather(0.1)`. Pause = `Set Global Time Dilation(0)` + flag.

**Verification**: `npm run echo` in the repo, Play → console shows scans, labels go green.
Stop the server → sim keeps running, JSONL keeps growing. `jq . < Saved/Sessions/*.jsonl` parses.

## Phase 6 — `WBP_ScenarioPanel` + `WBP_Sabotage` (`/Game/Sim/UI`)

Add both to the viewport from `BP_SimGameMode.BeginPlay` (`Create Widget` → `Add to Viewport`),
`Set Input Mode Game And UI`, show mouse cursor.

`WBP_ScenarioPanel`: a Scroll Box of rows, each `Text + Slider/CheckBox` bound to a `Config`
variable (`OnValueChanged` → set the variable). Buttons **Play/Pause** (`Paused` toggle),
**Reset** (`Open Level(L_Tower)` after `Config.Seed` set from a `SpinBox`), **Debug Traces** toggle,
**Camera** (Cutaway/Free: `Set View Target With Blend` to `CutawayCamera` actor or the spectator).
Text bindings: `SimTime`, `MsgCount`, `Connected` (green/red dot), current log file name.
Input actions from `DefaultInput.ini` (`Sim_TogglePause` = Space, `Sim_Reset` = R, …).

`WBP_Sabotage`: `ComboBox` of beacon ids (fill from `Building.Beacons`) + buttons **Kill / Revive /
Low battery / Move 5 m**; **Storm start/stop** (`Config.WeatherDrift` toggle + `SendEvent`);
**Door slam** (`SpinBox` floor → `Building.GustOnFloor = f`, `GustUntil = SimTime + GustSec`,
`SendEvent("gust")`); `ComboBox` of workers + **Toggle pocket**, **Toggle background** (call
`Sensors.StartScanTimer` after changing `AppState`), **Select for debug**.

## Phase 7 — package + record

- Same-seed determinism: Play twice with `Seed = 42`, `diff` the two JSONL files (strip the
  timestamped filename). Any diff = a `Random` node not using `Rng`, or a Tick dependency.
- Record `honest` (shifts w01–w04 only), `lobby-cheat` (w05–w06), `beacon-failure` (w01–w02 + kill
  `F12-A` at t=300) → copy into `sessions/` with those names.
- Platforms → Mac → Shipping → Package Project. Test the packaged app connects to `npm run echo`.
